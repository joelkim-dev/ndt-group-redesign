# NDT Group website redesign concept

A responsive redesign concept for [NDT Group Inc.](https://www.ndtgroupinc.com/), built as a static HTML, CSS, and JavaScript site.

## Structure

- `dist/` contains the editable production build used by the original preview deployment.
- `docs/` contains the GitHub Pages build.

## Local preview

Serve either directory with any static HTTP server. For example:

```sh
python3 -m http.server 4173 --directory dist
```
